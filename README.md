# ABES Engineering College — Original College Website Demo

This is a fresh React/Vite + Express presentation website. It uses ABES Engineering College as the institution name but uses an original layout and styling rather than cloning the ABES website.

## Run frontend
cd frontend
npm install
npm run dev

## Run backend
cd backend
copy .env.example .env
npm install
npm run dev

Frontend: http://localhost:5173
Backend: http://localhost:5001/api/health

The floating AI Assistant is ready to be connected to the P_200 AI/RAG backend.
